# Historical trajectory-representation configurations

The YAML files in this directory are preserved as provenance for completed
trajectory-representation studies. They may contain retired representation
fields, replay modes, or BC objective names and are not guaranteed to load
under the current strict configuration schema.

New experiments should use a maintained configuration under `configs/diffcrl/`.
These historical records must not be treated as current defaults or updated by
adding compatibility aliases for retired options.
